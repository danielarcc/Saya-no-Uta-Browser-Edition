## About

Saya no Uta — Browser Edition is an unofficial web adaptation of the original visual novel, developed to make the experience accessible directly through a browser.

The project aims to preserve the original atmosphere, interface, dialogue presentation, audio, and overall experience while adapting the game to modern web technologies.

## Content Changes

This edition is censored.

Sexually explicit scenes and dialogue considered unnecessary to the main story were removed or modified with AI assistance.

Not every scene or dialogue was manually reviewed. I was honestly too lazy to check everything, so some mistakes, inconsistencies, or explicit content may still remain.

This version should not be considered a completely verified or fully censored release.

## Features

- Browser-based visual novel experience
- Original-inspired interface and presentation
- Dialogue progression and text rendering
- Background music and sound effects
- Save and load functionality
- Configurable reading preferences
- Keyboard controls
- Support for compatible game content

## Development

Built with React, TypeScript, and Vite.

```bash
npm install
npm run dev
```

To build for production:

```bash
npm run build
```
